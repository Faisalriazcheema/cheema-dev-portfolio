# Cheema DevOps Portfolio

Public GitHub Pages site for the Cheema DevOps portfolio.

The site targets a worldwide audience and includes descriptive metadata, canonical URL, structured data, robots.txt and sitemap.xml.

The portfolio files live in `portfolio/public`. A GitHub Actions workflow builds the static site and deploys it to GitHub Pages when these files change.

The project tiles are clearly marked as sample concepts. The contact button currently links to `faisalriazcheema@gmail.com`.
